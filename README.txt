文化祭 POS 試作版

PC:
・注文受付
・商品価格設定
・最大在庫設定
・注文確定時に在庫減算
・注文履歴
・会計用Code 128バーコード発行

iPhone:
・Safariで「iPhone会計」ページを開く
・カメラでバーコードを読み取る
・注文内容と合計金額を表示
・会計完了を記録

注意:
これは第一試作です。ブラウザのlocalStorageを使っているため、PCとiPhoneが別端末の場合、注文履歴を自動共有する本格的な同期はまだ入っていません。
本番版では共有サーバー/APIを追加し、PCで発行した注文をiPhoneから照会できるようにするのがおすすめです。
カメラ読み取りはHTTPSまたはlocalhostでの利用を推奨します。
