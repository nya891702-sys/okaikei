文化祭POS・シンプル版

PC:
注文受付、価格設定、最大在庫設定、在庫減算、注文履歴、会計用バーコード発行。

iPhone:
バーコードをカメラで読み取り、注文内容と金額を表示して会計完了。

設計:
PCとiPhoneのデータ連携はしません。
バーコード自体に「注文番号 + 8商品の個数」を入れます。
iPhoneはバーコードから注文内容を復元します。

注意:
価格はiPhone側ではなく、iPhoneページを開いた端末にも設定値が必要なため、本番利用では「価格もバーコードに埋め込む」方式に変更するのがより安全です。
カメラ機能はHTTPSまたはlocalhostで動かしてください。
